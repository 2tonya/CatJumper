CatJumper — аркада про кота на крышах

Чистый HTML/CSS/JS, без зависимостей, сборщиков и бэкенда.
Открывается двойным кликом по index.html.

Что внутри:
- canvas 480x720, процедурная генерация с гарантией достижимости
- coyote time, буфер ввода, двойной прыжок, JUMP_CUT
- 4 типа платформ: solid, moving, crumble, bouncy
- шипы, монеты, частицы, squash-and-stretch
- параллакс-город, плавный переход в космос
- рекорд в localStorage, управление с клавиатуры и тача

Запуск локального прогона:
  node cj-server.js   # затем открыть http://127.0.0.1:8123/index.html
